# QuickSlot v1.9.0

Версия 1.9.0 делает профили удобнее при игре на нескольких серверах и в разных мирах.

Что изменилось:
- QuickSlot запоминает активный профиль отдельно для каждого мультиплеерного сервера;
- для одиночных миров профиль запоминается отдельно по имени мира;
- при следующем входе сохранённый профиль автоматически восстанавливается;
- выбор профиля через меню или хоткей `V` автоматически обновляет привязку текущего сервера/мира;
- в разделе «Профили» появился переключатель «Профиль для сервера»;
- функцию можно отключить и использовать один глобальный профиль как раньше;
- данные хранятся только локально в `config/quickslot-contexts.properties`;
- сохраняется не более 64 последних серверов/миров;
- адреса серверов нормализуются, чтобы разный регистр и лишние пробелы не создавали дубликаты;
- добавлены автоматические тесты ключей контекста;
- все настройки и профили версии 1.8.0 сохраняются без миграции.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
