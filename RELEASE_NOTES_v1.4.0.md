# QuickSlot v1.4.0

В этой версии я сделал Auto Refill более точным и добавил отдельные функции для работы с основным инвентарём.

Что нового:
- Auto Refill можно включать и выключать отдельно для каждого из 9 слотов;
- настройки слотов Auto Refill сохраняются отдельно для профилей «Обычный», Rush и Bridge;
- отключённый Auto Refill не заполняет пустой слот и не дозаполняет неполный стек;
- добавлено объединение одинаковых стеков в основном инвентаре;
- объединение стеков работает независимо от автосортировки и не затрагивает хотбар;
- после закрытия обычного инвентаря или контейнера QuickSlot делает короткую паузу, чтобы не мешать ручным действиям;
- паузу после ручной работы можно выключить;
- добавлен отдельный раздел «Инвентарь»;
- экран Auto Refill теперь содержит режим, порог и переключатели всех 9 слотов текущего профиля;
- настройки v1.3.0 сохраняются без сброса.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
