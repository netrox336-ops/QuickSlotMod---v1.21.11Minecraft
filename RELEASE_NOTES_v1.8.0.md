# QuickSlot v1.8.0

Версия 1.8.0 усиливает защиту ручной работы с инвентарём и делает автоматические действия устойчивее к задержкам сервера.

Что изменилось:
- QuickSlot полностью прекращает автоматические перестановки, пока предмет находится на курсоре;
- после освобождения курсора добавлена короткая защитная пауза перед возобновлением работы;
- открытие инвентаря или контейнера отменяет текущие автоматические действия, не обнуляя накопленную защиту от сетевых задержек;
- фиксированная пауза после таймаута заменена адаптивным backoff;
- при повторных таймаутах задержка растёт ступенчато: 4, 8, 16 и максимум 32 клиентских цикла;
- после трёх успешных подтверждённых действий QuickSlot постепенно возвращается к обычной скорости;
- устаревшие действия по-прежнему не повторяются вслепую;
- история задержек полностью сбрасывается при смене игрока, мира, контейнера или профиля;
- добавлены автоматические JUnit-тесты для backoff-политики;
- тесты запускаются обычной командой `gradle build` и в GitHub Actions;
- настройки версии 1.7.0 сохраняются без миграции.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
