# QuickSlot v1.5.0

В этой версии я добавил более точный выбор блоков и отдельное управление автоматическим улучшением снаряжения.

Что нового:
- настраиваемый приоритет блоков отдельно для профилей «Обычный», Rush и Bridge;
- поддерживаются группы: шерсть, доски, эндерняк, терракота, стекло, обсидиан и остальные блоки;
- новый переключатель «Сохранять текущий блок»;
- если сохранение включено, QuickSlot сначала ищет тот же конкретный блок, который уже использовался в слоте;
- если сохранение выключено, мод может заменить блок на материал с более высоким приоритетом;
- автоматическое улучшение меча, кирки и топора включается независимо для каждого типа;
- добавлен раздел «Выбор» и отдельный редактор порядка блоков;
- при смене профиля запомненный конкретный блок сбрасывается;
- настройки v1.4.0 сохраняются и автоматически дополняются новыми параметрами.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
