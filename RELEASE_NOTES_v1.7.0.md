# QuickSlot v1.7.0

В этой версии Auto Refill стал полностью послотовым, а профилями стало удобнее управлять прямо в игре.

Что изменилось:
- для каждого из 9 слотов каждого профиля теперь отдельно сохраняются включение Auto Refill, режим и порог;
- экран Auto Refill переработан под выбор конкретного слота;
- старые общие режим и порог из предыдущих версий автоматически переносятся во все слоты при первом запуске;
- добавлено копирование активного профиля в `Обычный`, `Rush` или `Bridge`;
- при копировании переносятся раскладка, все настройки Auto Refill и выбор блоков;
- добавлен полный сброс активного профиля с подтверждением;
- глобальные настройки HUD, защиты, инвентаря и автоулучшения снаряжения при копировании и сбросе не меняются;
- Auto Refill продолжает работать через безопасную очередь с проверкой исходных слотов, подтверждением результата и таймаутом;
- конфиг версии 1.6.0 мигрирует автоматически без потери существующих настроек.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
