# QuickSlot v1.9.1 — Hot Bug Fix

Версия 1.9.1 — аварийный hotfix критических вылетов QuickSlot на Minecraft Java 1.21.11.

Исправлено:
- устранён критический вылет версий 1.5.0–1.9.0 на первом клиентском тике: `QuickSlotConfig` больше не создаёт singleton до инициализации стандартного приоритета блоков;
- кэш предпочитаемых блоков теперь сразу заполняется `ItemStack.EMPTY`, а не остаётся с `null`-элементами;
- добавлена дополнительная защита от `null` в логике выбора предпочитаемого блока — это закрывает падение того же класса, наблюдавшееся в 1.4.0 после входа в мир;
- добавлены защитные проверки для профиля и массива приоритетов блоков;
- добавлен аварийный fail-safe: если обработчик QuickSlot неожиданно получает `RuntimeException` или `LinkageError` во время клиентского тика либо отрисовки HUD, мод отключается до перезапуска клиента и записывает стек ошибки в лог вместо повторного падения Minecraft;
- добавлен регрессионный JUnit-тест статической инициализации `QuickSlotConfig`, чтобы ошибка порядка `static`-полей не вернулась в следующих версиях;
- существующие настройки 1.9.0, профили и `quickslot-contexts.properties` продолжают использоваться без миграции.

Совместимость:
- Minecraft Java 1.21.11;
- целевая версия Forge: 61.2.0;
- мод работает только на клиенте.

В предоставленном crash-log игра была запущена на Forge 61.1.0. Он входит в заявленный диапазон Forge 61.x, однако для тестирования и дальнейшей поддержки рекомендуется Forge 61.2.0, на котором собирается QuickSlot.
