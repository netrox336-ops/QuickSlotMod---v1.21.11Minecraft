# QuickSlot

QuickSlot — клиентский мод для Minecraft Java 1.21.11 + Forge, который автоматически поддерживает порядок в хотбаре во время игры.

Я сделал его для ситуаций, когда не хочется постоянно вручную возвращать меч, блоки, инструменты и BedWars-предметы на привычные места.

## Что умеет

- автоматически раскладывает предметы по заданным слотам хотбара;
- пополняет назначенные слоты из основного инвентаря;
- автоматически выбирает более сильный меч, кирку или топор;
- отдельно умеет раскладывать блоки, золотые яблоки, ножницы, лук, стрелы, TNT, fireball, эндер-жемчуг, лестницы и воду;
- убирает железо, золото, алмазы и изумруды из хотбара и складывает их в основной инвентарь;
- поддерживает профили `Normal`, `Rush` и `Bridge`;
- показывает HUD с количеством Iron, Gold, Diamond и Emerald;
- позволяет перетаскивать HUD мышкой и менять его масштаб;
- позволяет независимо включать автосортировку, перенос ресурсов и HUD.

## Настройки

Нажмите `O`, чтобы открыть меню QuickSlot. В нём можно настроить все 9 слотов текущего профиля, включить или выключить основные функции и открыть редактор HUD.

Нажмите `P`, чтобы быстро переключить активный профиль. Обе клавиши можно переназначить в обычных настройках управления Minecraft.

## Установка

1. Установите Minecraft Java 1.21.11.
2. Установите Forge 61.2.0.
3. Скачайте `quickslot-1.1.0.jar` из раздела Releases.
4. Поместите файл в папку `.minecraft/mods`.
5. Запустите игру.

QuickSlot работает только на клиенте — устанавливать его на сервер не требуется.
