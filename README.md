# QuickSlot

QuickSlot — клиентский мод для Minecraft Java 1.21.11 + Forge, который автоматически поддерживает порядок в хотбаре во время игры.

Я сделал его для ситуаций, когда не хочется постоянно вручную возвращать меч, блоки, инструменты и BedWars-предметы на привычные места.

## Что умеет

- автоматически раскладывает предметы по заданным слотам хотбара;
- защищает выбранный игроком слот и не переставляет предмет прямо из руки;
- пополняет назначенные слоты из основного инвентаря;
- поддерживает три режима Auto Refill: только когда слот пуст, ниже заданного порога или постоянное заполнение стака;
- позволяет отдельно настроить включение, режим и порог Auto Refill для каждого из 9 слотов каждого профиля;
- запоминает конкретный блок, который использовался в слоте, и при желании старается продолжать использовать именно его;
- позволяет настроить порядок выбора блоков отдельно для профилей `Обычный`, `Rush` и `Bridge`;
- различает шерсть, доски, эндерняк, терракоту, стекло, обсидиан и остальные блоки;
- позволяет независимо включать автоматическое улучшение меча, кирки и топора;
- отдельно умеет раскладывать блоки, золотые яблоки, ножницы, лук, стрелы, TNT, fireball, эндер-жемчуг, лестницы и воду;
- убирает железо, золото, алмазы и изумруды из хотбара и складывает их в основной инвентарь;
- при желании объединяет одинаковые стаки в основном инвентаре, не затрагивая хотбар;
- делает короткую паузу после закрытия обычного инвентаря или контейнера, чтобы автоматика не мешала ручной работе;
- выполняет автоматические перестановки строго по одной и ждёт подтверждения результата перед следующим действием;
- при лаге или изменившемся инвентаре отменяет устаревший план вместо повторного клика по старому состоянию;
- поддерживает профили `Обычный`, `Rush` и `Bridge` с отдельной раскладкой, Auto Refill и приоритетом блоков для каждого;
- умеет копировать все профильные настройки из активного профиля в другой;
- умеет полностью сбрасывать активный профиль к стандартным значениям с отдельным подтверждением;
- показывает HUD с количеством Iron, Gold, Diamond и Emerald;
- отдельно показывает компактный статус QuickSlot с активным профилем и состоянием автосортировки;
- позволяет независимо включать HUD ресурсов и HUD состояния;
- ресурсы и статус используют общее настраиваемое положение и масштаб.

## Настройки

Нажмите `O`, чтобы открыть меню QuickSlot. В нём можно настроить все 9 слотов текущего профиля, защиту выбранного слота, HUD, профиль, Auto Refill, работу с инвентарём и выбор предметов.

В разделе **«Выбор»** можно:

- включить или выключить сохранение текущего типа блока;
- расставить приоритет блоков от самого желательного к наименее желательному;
- отдельно включить или выключить автоматическое улучшение меча, кирки и топора.

Если сохранение текущего блока включено, QuickSlot сначала ищет тот же конкретный материал, который уже использовался в слоте. Если оно выключено, мод ориентируется на заданный порядок блоков.

В настройках **Auto Refill** сначала выбирается слот хотбара, после чего для него отдельно задаются:

- включён ли Auto Refill вообще;
- режим **«Когда пусто»**, **«Ниже порога»** или **«Держать максимум»**;
- порог от 1 до 64 предметов для режима «Ниже порога».

Все эти значения сохраняются отдельно для каждого из 9 слотов профилей `Обычный`, `Rush` и `Bridge`. При первом запуске версии 1.7.0 старые общие режим и порог из предыдущих версий автоматически переносятся во все слоты, поэтому привычное поведение не сбрасывается.

В разделе **«Профили»** можно выбрать активный профиль, скопировать его настройки в другой профиль или сбросить активный профиль к стандартным значениям. При копировании переносятся раскладка хотбара, Auto Refill и приоритеты блоков. Глобальные настройки HUD, защиты, объединения стеков и снаряжения не изменяются.

В разделе **«Инвентарь»** находятся объединение одинаковых стеков и пауза после ручной работы с инвентарём.

Начиная с версии 1.6.0 все автоматические действия QuickSlot проходят через одну очередь. Перед выполнением мод ещё раз проверяет исходные слоты, а после клика ждёт стабильного результата. Если сервер отвечает слишком долго или состояние уже изменилось, старое действие сбрасывается и позже строится новый план по актуальному инвентарю.

По умолчанию `V` быстро переключает активный профиль: `Обычный` → `Rush` → `Bridge` → `Обычный`. При смене профиля QuickSlot сбрасывает ранее запомненный конкретный блок и текущую очередь действий, чтобы настройки профилей не смешивались. Клавиши можно переназначить в обычных настройках управления Minecraft.

## Установка

1. Установите Minecraft Java 1.21.11.
2. Установите Forge 61.2.0.
3. Скачайте `quickslot-1.7.0.jar` из раздела Releases.
4. Поместите файл в папку `.minecraft/mods`.
5. Запустите игру.

QuickSlot работает только на клиенте — устанавливать его на сервер не требуется.
