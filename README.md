# QuickSlot

QuickSlot — клиентский мод для Minecraft Java 1.21.11 + Forge, который автоматически поддерживает порядок в хотбаре во время игры.

Я сделал его для ситуаций, когда не хочется постоянно вручную возвращать меч, блоки, инструменты и расходники на привычные места.

## Что умеет

- автоматически раскладывает предметы по заданным слотам хотбара;
- пополняет блоки и другие предметы из инвентаря;
- убирает железо, золото, алмазы и изумруды из хотбара;
- поддерживает профили `Normal`, `Rush` и `Bridge`;
- показывает отдельный HUD с количеством Iron, Gold, Diamond и Emerald;
- позволяет менять правила каждого слота через игровое меню.

## Установка

1. Установите Minecraft Java 1.21.11.
2. Установите Forge 61.2.0.
3. Поместите `quickslot-1.0.0.jar` в папку `.minecraft/mods`.
4. Запустите игру.

QuickSlot работает только на клиенте — устанавливать его на сервер не требуется.

## Управление

- `O` — открыть настройки QuickSlot;
- `P` — переключить активный профиль.

Обе клавиши можно переназначить в обычных настройках управления Minecraft.
