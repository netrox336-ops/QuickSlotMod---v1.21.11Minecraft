# QuickSlot v1.3.0

В этой версии я сделал работу QuickSlot безопаснее во время активной игры и добавил отдельный HUD состояния.

Что нового:
- защита выбранного слота хотбара включена по умолчанию;
- пока слот выбран, QuickSlot не использует его ни как цель, ни как источник автосортировки;
- перенос Iron, Gold, Diamond и Emerald тоже не трогает выбранный слот;
- добавлен HUD состояния с активным профилем и состоянием автосортировки;
- HUD состояния можно выключить отдельно от счётчика ресурсов;
- оба HUD используют общее положение и масштаб;
- редактор HUD показывает сразу актуальную комбинацию ресурсов и статуса;
- для новых установок клавиша V переключает «Обычный» → Rush → Bridge → «Обычный»;
- главное меню обновлено под новые настройки.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
