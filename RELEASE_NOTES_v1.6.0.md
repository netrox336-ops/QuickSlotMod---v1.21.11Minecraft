# QuickSlot v1.6.0

В этой версии я сосредоточился на стабильности автоматических действий с инвентарём.

Что изменилось:
- автосортировка, Auto Refill, перенос ресурсов и объединение стеков теперь используют одну общую очередь;
- QuickSlot выполняет только одно автоматическое действие за раз;
- перед выполнением мод повторно проверяет исходные слоты и отменяет устаревший план;
- после клика результат должен подтвердиться несколько последовательных циклов;
- следующая перестановка не запускается, пока предыдущая не подтверждена;
- при таймауте старое действие удаляется без повторного клика по прежнему состоянию;
- после неудачного действия используется короткая защитная пауза, после которой строится новый план;
- очередь сбрасывается при смене профиля, игрока, мира, контейнера и при открытии инвентаря;
- пауза после ручной работы с инвентарём сохранена;
- все настройки v1.5.0 продолжают работать без миграции.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
