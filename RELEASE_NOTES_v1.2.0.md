# QuickSlot v1.2.0

В этой версии я сделал автопополнение хотбара заметно гибче и перенёс удобное управление профилями из версии для Minecraft 1.8.9.

Что нового:
- три режима Auto Refill: «Когда пусто», «Ниже порога» и «Держать максимум»;
- порог пополнения настраивается от 1 до 64 предметов;
- QuickSlot запоминает последний тип блоков в назначенном слоте и старается пополнять именно его;
- если нужных блоков больше нет, используется самый большой подходящий стек;
- частично заполненные стаки теперь можно автоматически дозаполнять из основного инвентаря;
- добавлен отдельный экран выбора профиля;
- профиль Normal в интерфейсе теперь называется «Обычный»;
- настройки и раскладки из v1.1.0 сохраняются автоматически.

Версия предназначена для Minecraft Java 1.21.11 + Forge 61.2.0 и работает только на клиенте.
